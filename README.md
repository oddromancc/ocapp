# ocapp

Подбор вакансий по резюме

## Функционал на данный момент 
- Создание резюме и вакансий
- Подбор соответствущих по навыкам и образованию вакансий

## Инструкция по установке

0. Клонируйте репозиторий: `git clone https://github.com/oddromancc/ocapp.git`
1. Создайте виртуальное пространство: `python -m venv .venv`
2. Создайте проект: `npm init -y`
3. Установите tailwind и daisyui: `npm install tailwindcss@latest @tailwindcss/latest daisyui@latest`
4. Создайте .css: `npm run build:css`
5. Запустите: `flask --app .\ocapp.py`
